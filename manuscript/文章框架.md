# 中文综述的文章框架

写作日期：2026-10-03。前沿文献截点：2026-10-02；本轮仅补充此前发表的背景来源。体裁为专题叙述性综述，暂用通用统计计算期刊体例，中文优先，不将技能默认的英文输出用于本稿。

## 题目与核心论点

**链内与时间并行 MCMC：统计保证、可并行性与推断成本**

在给定硬件和后验精度要求下，链内并行的价值取决于统计保证、数值求解成本与硬件执行成本的共同作用；现有成果需要沿这三个方面比较，才能判断何时优于经过合理调参的多链基线。

文章的贡献是解释和综合已有成果：区分轨迹等价、目标不变性和有限时间误差；连结预取、多提议与 Picard/Newton 时间并行；以达到推断精度的时间重新解释加速证据。本文不提出新采样算法、新定理或新实验结果，也不声称首篇或穷尽综述。

## 术语与符号表

| 规范写法 | 首次定义或用途 | 避免的混用 |
|---|---|---|
| 马尔可夫链蒙特卡洛（MCMC） | 后验积分的相关抽样方法 | 不简称成所有贝叶斯推断 |
| 链内并行 | 同一链的一次转移或一段轨迹内分配计算 | 与多链并行分别讨论 |
| 时间并行 | 沿采样迭代或积分步的顺序轴并行 | 不等同于观测时间序列分块 |
| 多提议 MCMC | 每次更新产生多个提议状态的算法族 | 统一采用“多提议”，不与粒子 MCMC 共用 PMCMC 缩写 |
| 轨迹等价 | 固定初值和随机输入后与指定顺序算法一致 | 不等于已从目标精确独立抽样 |
| 目标不变性 | 转移核保持目标概率分布 | 不等于遍历性或快速混合 |
| 有效样本量（ESS） | 特定估计对象的方差效率量 | 不当作近似偏差检验 |
| 蒙特卡洛标准误（MCSE） | 估计量的 Monte Carlo 不确定性 | 与后验标准差、初始化偏差分别表述 |
| No-U-Turn Sampler（NUTS） | 动态选择 HMC 轨迹长度的采样器 | FSM 多链调度不等于单链时间并行 |
| $\pi,\ K$ | 目标分布、转移核 | 处理器数统一记为 $P$，不用 $K$ |
| $d,\ N,\ C,\ M,\ J,\ w$ | 状态维度、轨迹长度、链数、提议数、外层求解轮数、窗口长度 | 原论文符号必要时明确换记号 |
| $W,\ D,\ T_P$ | 总工作量、执行深度、$P$ 个处理器上的时间 | 状态维度不用 $D$ |
| $m,\ L,\ \kappa$ | 强凸常数、光滑常数、条件数 $L/m$ | Picard/Newton 外层迭代数不用 $m$ |
