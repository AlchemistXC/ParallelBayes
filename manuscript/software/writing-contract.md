# 软件论文写作与证据契约

类型：方法/软件与计算实验；中文；未指定期刊；现有综述独立保留。

论证：同一目标与固定随机输入使转移核执行成本可被核对，但数值轨迹核验、统计误差和完整工作流成本必须分别呈现；本研究通过可复现 R/JAX/Stan 接口和冻结基准测量这一边界。当前 CPU 开发结果不支持时间并行净优势，GPU不在本轮范围，原生Windows后端未实现。

| 标准术语 | 定义/固定写法 |
|---|---|
| 转移核 | 指定概率递推，不与执行器混用 |
| 执行器 | 顺序、非重叠窗口 quasi-DEER、Online Picard |
| 轨迹核验 | 固定实际随机数组下的数值误差和接受事件检查；不写位级相等 |
| 原递推残差 | 非线性硬接受递推的局部残差；不等于全局路径误差界 |
| 完整工作流时间 | 单次已启动研究会话内，编译/预热/执行/核验/传输等；环境安装和重复计时探测单列 |
| 解析 MSE | 对解析真实期望的独立重复平方误差 |
| 参考平方差 | 对有限 NUTS 参考的平方差；参考误差单列，不改名真实 MSE |
| SBC | 从先验生成参数和数据、重新拟合；有限重复与相关抽样限制明确 |

引言采用技术问题路径：时间依赖—两类固定点方法—目标与保证混淆—可核对的比较问题。正文依次给计算契约、验证证据、协议、实测和适用边界。实现细节和逐任务日志放复现材料。

| 证据 | 正文角色 | 去向 |
|---|---|---|
| 模型/轨迹/错误注入与 R 检查 | 必要可信性依据 | 验证节；完整日志附录 |
| 192 项开发探测 | 开发范围决定，不作正式效果估计 | 简短结果和附表 |
| 正式成对成本与误差 | 主要证据，完成后才填数 | 结果与主图 |
| 失败/发散/负结果 | 结论边界 | 正文保留 |
| 单次编译日志、完整 seed 列表 | 可复现性细节 | 协议/机器可读材料 |
| GPU未实现且暂缓 | 研究范围 | 讨论明确不属于本版能力和实证结论 |

没有新采样算法、通用 Stan→GPU 编译器、自动选择器、现代多链统治性优势等声明。文章不以接口封装本身宣称首次贡献。最终作者和单位待用户决定；不编造署名。

计时实现核对：完整工作流采用 task_elapsed_including_output − timing_replay_overhead + summary/diagnostic time；另保留 sampler API 的 timing.total。这样不会遗漏模型建立、写盘和校验和成本。后验摘要计时在读取原始数组之后开始，避免把分析端重新解压文件当作生产推断的第二次I/O。该落实对应冻结协议的完整成本口径，不改变核、模型、采样预算或主要误差函数。

审查修订主线：明确支持组合→解析/现代诊断定位差异→重复工作与批处理吞吐机制→可独立解压重建。新增机制为72任务、3随机数组/格，不以出现加速为验收；拆分测量带来扰动，不声称生产剖面。
