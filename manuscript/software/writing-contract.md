2026-10-05整合修订。类型：方法/软件与计算实验；中文；通用期刊格式，未定投稿期刊。现有综述独立保留；作者/单位待研究者确认。

核心论证：固定目标、坐标和实际随机数组使指定轨迹的执行成本可核对，但路径数值有效、原尺度输出一致、诊断一致与有限预算推断精度是不同命题。Mac JAX CPU负结果与Windows torch CUDA Picard局部执行收益共同支持这一分层评价，不能合并成通用硬件或算法排名。

当前能力：Stan/BridgeStan仅CPU顺序RWM/MALA；明确JAX目标支持CPU相应MH组合及BlackJAX；明确torch目标已核验原生Windows CPU/CUDA MH，时间执行仍含Python主机控制。CPU Pyro NUTS九目标串行/spawn是独立研究CLI，未接入通用torch pb_sample；GPU NUTS、Windows Stan编译和融合设备控制未验收。

| 标准术语 | 定义及禁止混淆 |
|---|---|
| 转移核 / 执行器 | 概率递推 / 计算指定递推的顺序、窗口quasi-DEER、Online Picard方式 |
| 轨迹核验 | 实际数组下的数值路径和接受事件检查，不自动表示浮点逐位相等 |
| 原递推残差 | 硬分支递推的局部残差，不是全路径误差界或统计偏差界 |
| 参数变换核验 | 原尺度输出的独立要求；跨系统60份逐位失败不因误差小改称通过 |
| 准备后执行 | 同一程序的显式同步缓存测量，技术重复不增加统计n |
| 历史CPU完整工作流 | 原协议的task_elapsed减重放加诊断，非新进程冷启动 |
| 普通批量工作流 | 新接口子进程从创建到退出；给定配置与已封存输入，不包含离线调参/环境安装/最外层R |
| 含审计执行调用 | 包含普通流程、独立核验及封存；与普通时间嵌套，不相加 |
| 完整成本未知 | 任一实际尝试缺测时完整值不可用，保留已知部分，不填零 |
| 解析MSE / 参考平方差 | 解析真实期望 / 有限参考；L2等未定参考不能变成零误差 |
| SBC | 先验生成参数和数据再拟合；同数据集的不同工作流不是独立校准证据 |
| 独立重复 | 完整四链拟合；单链、重试、重放、同一数组的跨设备副本不扩充n |
