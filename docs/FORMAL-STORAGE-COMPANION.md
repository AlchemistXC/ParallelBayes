## 如何用于Windows启动前核对

仍使用[同一正式研究提示词](../handoff/windows-completion/CODEX-PROMPT-FORMAL-STUDY.md)，无需再跑有限v2、旧F2或安装验收。提示词只补充本账本，冻结执行仍在精确0ba5643工作树，保留原内存/磁盘安全规则。

1. 将执行原件、导出tar、独立解压、分析、备份映射到实际卷；记录每个卷空闲量，包含历史材料。
2. 按上述数组角色与副本数记账，并为未计日志、失败、索引及文件系统开销明确预留；资源不足就保留等待，不缩减科学网格或删除历史。
3. 每阶段记录实际文件长度与卷余量，持续采用既定运行保护。单项4GiB启动/1GiB储备不能替代整个研究的容量安排。
4. 完整原件先保留Windows。没有完整回传容量时先交协议、状态、清单和分析小包；不能因此宣布F5完整独立重建完成。

不要求购买设备。当前没有原生Windows实时执行句柄；本机也不能证明Windows当前空闲空间或备份可靠性。实际容量/目录安排由Windows端预检并回传。
