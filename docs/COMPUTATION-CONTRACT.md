# 计算契约 v0.1

唯一内核源码在 `r-package/inst/python/parallelbayes/`，Python 和已安装 R 包均使用该实现。

## 模型与坐标

原生模型使用显式无约束坐标 q。正值例的 θ=exp(q)，必须包含变量变换 Jacobian。高斯、logistic、lognormal 和共轭正态例各有独立 NumPy 密度/解析梯度。目标和数据采用完整 JSON 指纹。

Stan 模型通过 BridgeStan 2.7.0 编译；`propto=True, jacobian=True`。跨提供方式比较相对 log density、同坐标梯度和约束变换，允许参数无关常数差。一次模型实例只在本进程串行使用，不共享指针，不使用 Stan 内部线程。C++ 负责密度与自动微分，Python 串行循环负责转移调度；这部分开销计入 CPU 软件工作流，不能归因于统计算法。

任意 Stan 源码没有原生 JAX/GPU 自动翻译。当前显式配对的基准目标之外，用户须提供并验证原生实现，不能仅更换 backend 字符串。

## 固定核

MALA: y=q+h∇ℓ(q)+sqrt(2h)z，log α=ℓ(y)−ℓ(q)−[||q−y−h∇ℓ(y)||²−||y−q−h∇ℓ(q)||²]/(4h)。接受当 log u<log α；拒绝保持 q。h 不是通常写作 σ 的噪声标准差。

RWM: y=q+s z，log α=ℓ(y)−ℓ(q)，同一接受规则。拒绝自环计为一个转移，不只计移动。

Philox 生成实际 z、log u，按链/步/参数确定形状。采样种子与 quasi-DEER 的 Rademacher 导数探测种子分离；记录实际数组指纹。相同整数种子只能在本定义下生成共同随机输入，不能据此声称与 NUTS 共享随机性。

## 时间执行器

- 顺序：JAX scan；独立 oracle 使用 NumPy 循环，非同一函数的第二次调用。
- quasi-DEER：非重叠分块、固定窗口初猜、Rademacher JVP 估计对角导数、截断对角导数、仿射结合扫描。硬接受前向，sigmoid 直通导数。每次更新重新测量硬转移原递推残差，max |q_t−F(q_{t−1})|/(atol+rtol|F|)≤1 才停止。该残差不等于全轨迹误差界或统计精确性证明。已实现版本与上游滑动窗口策略不同；正式报告按本实现命名。
- Online Picard：并行计算接受增量、前缀和更新轨迹，再检查新前驱下的接受事件；最长一致前缀推进滑动窗口。由论文算法独立实现，未复制 ParallelMH 仓库源码。浮点加法顺序可能不同，所以只声明增量/分支一致性及独立数值核验，不声明逐位轨迹等价。

quasi-DEER 不修补 NaN、不截断状态；对角导数裁剪有计数。记录求解次数、原递推残差、确认前缀、前向/JVP 调用量和停止状态。状态码：0 达到执行器输出标准；1 数值迭代上限；2 非有限状态或无法推进。独立审计不通过也返回 failed。

如果显式选择 sequential 回退，则重用原随机数组重新执行整个指定轨迹，保留原始失败诊断、回退时间以及已花成本。不重抽噪声、不选择较快链。首版不声称已实现只重算未确认后缀的优化。

## 验证与成本

未通过标准的轨迹仅存为 failed_trajectory，不进入 posterior 样本。完成采样不代表平衡、混合良好或后验正确；NUTS 发散、模式探索和统计误差须另审查。

同步设备后结束执行计时。编译、输入、预热、执行、传输、独立核验、回退分别报告；CPU RSS 是每 20 ms 采样的进程峰值，不是精确设备峰值。GPU allocator 提供的内存统计单列，不把不同定义内存混算。整个任务含输出的时间也保存。

R 接口返回 `posterior::draws_array`，顺序为 iteration × chain × variable，独立 record 保留诊断与实际配置。不支持的核/执行器/设备组合报错。

## 完整成本的分析实现

原始 `timing.total` 是采样API调用时间；正式分析中另存为 `t_sampler_api`。主要完整成本 `t_total` 使用逐任务墙钟减去仅为基准而增加的缓存重放开销，再加正常内存样本上的后验函数摘要/诊断计算时间。任务墙钟包括目标建立、原始结果写盘、压缩和校验和。图表同时给缓存执行与完整成本，不把全部差异归因于采样循环。

`coordinate_id` 是提供方式中的坐标标签，不是独立的全局模型等价证书；目标匹配同时需要完整 spec、kind、参数顺序、变换和密度/导数检查。H1/H2 的不同映射由 kind 和 constrain 明确规定，不能仅凭默认标签相同就直接比较梯度。

## 审查后的分析保护

分析入口核对冻结协议自身、运行 manifest 与完整任务身份集合，并输出分析脚本和参考来源校验和。常量非恒定函数的 Rhat 不可判定；不会将零观察事件解释成零参考误差。L2 的符号事件在现有参考样本中全为零，所以全函数最大误差的参考精度未确定，相应达标判断保持未判定。

每组另列全部尝试成本及失败成本；误差曲线的时间与误差都以正常输出为条件。参考敏感性使用共同正态扰动和对角协方差，这是工作假设，不是联合参考误差的精确估计。基本重复 bootstrap 区间单独保留。

独立路径核验在无约束坐标执行，要求接受事件零失配，以及每链最大绝对路径差不超过 `100 * (atol + rtol * max(1, max(abs(path))))`。这与逐坐标硬残差阈值不同；100 倍系数是预先固定的开发审计阈值，不是误差传播定理。

RSS 仅指采样 API 期间进程绝对 RSS 的采样峰值，包含进程先前驻留分配，不覆盖模型建立、压缩写盘或子进程。MH 的 `draws` 是全部转移数，`warmup` 不自动额外执行或丢弃 MH 转移；正式任务的丢弃段由 `task.discard` 执行。NUTS 的 `warmup` 才是额外自适应预热步数。

退化诊断的机器可读数值为JSON null，并附`split_rhat_state`区分全无变化（未定义）和链间分离但链内方差为零（无穷大）。这些都不是理想收敛。候选的内存门槛是基于数组形状的工作空间估计，不能解释为编译器、模型构建和设备分配峰值的严格上界。
