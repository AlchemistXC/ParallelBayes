9个目标的新旧初值和MH实际数组全部相同；36对MH接受事件失配0，原始路径最大差2.665e-15。该对照只说明本次兼容修订的影响，不能把v1已隔离的输出重标为成功。

v2仍有3条NumPy slogdet警告，原日志保留。所有9个实际因子均为正对角下三角矩阵，其log行列式与独立的对角对数求和最大差2.843e-14；没有观察到非有限值。没有据此推断所有底层库运算均可靠，也没有关闭警告。

```text
python scripts/completion/inference_readiness.py run --protocol benchmark/protocols/inference-readiness-mac-v2.json --source WELLS_SOURCE --output NEW_RUN
python scripts/completion/analyze_inference_readiness.py --run COMPLETED_RUN --output NEW_ANALYSIS --rscript Rscript
```
