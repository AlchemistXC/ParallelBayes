# 缓存执行及中断恢复的外层成本

2026-10-05。数值技术验证源码 `8a24cb150ff757f97e0a6b43dfd1ee090e133488`，归档分析源码 `5c314cd3ebb7bf381ca43a92d6fcc897c7d654b9`。继[普通/审计流程计时](MEASURED-WORKFLOW.md)之后，本次补齐有限 Mac MH 配置的准备后执行与每次协调调用记录；**尚未完成正式网格、最大任务或 Windows 验收**。

## 准备后执行接口

`cached_execution.PreparedExecutor` 接收已有目标、核配置和实际随机数组，检查形状、有限性、输入角色、设备、内存估计及初值，持有独立设备副本。它直接调用原 `transition` 和 `execute`，不改数值算法，不重抽随机数，不隐式回退。调用者随后修改原输入不会改变已经准备的任务。

执行墙钟从已同步设备上的 `execute` 调用前开始，计至调用完成后的设备同步。原执行器的输出分配、求解轮次、遥测及 Python 控制/标量同步均包含；准备数据、结果传输、参数变换、写盘和独立审计不在这个时间内。首次执行另存，后三次标为准备后重放。这里使用 torch eager，没有新增显式编译或融合设备控制；首次调用仍可能包含框架初始化，不能把其时间记为零。每次结果最初均为候选、`samples_eligible=false`，求解失败也保留原轨迹及耗时。

冻结技术协议 `cached-cost-technical-mac-v1` 复用原 G1 的四种 MH 实际输入，各执行一次初始调用及三次重放，共16次执行、16次独立 NumPy 路径审计。所有输出与**各自历史**无约束路径及接受数组逐位一致，接受事件无失配。核验在执行计时之外完成。本次没有测量缓存 NUTS；真实四进程 NUTS 的完整流程时间保留既有定义。

| 工作流 | 初次执行秒数 | 三次准备后执行秒数 |
|---|---:|---|
| 顺序 RWM | 0.008223 | 0.007354、0.007205、0.007984 |
| 顺序 MALA | 0.507361 | 0.032470、0.027472、0.031053 |
| Online Picard | 0.010487 | 0.009508、0.008963、0.008959 |
| quasi-DEER | 0.754280 | 0.263407、0.269172、0.264991 |

这只是四链、80步的有限 G1 技术输入，按固定工作流次序运行；三次重放不是三个独立后验实验。表格不提供性能排序的置信区间，也不与上一轮在不同进程/时刻测得的普通墙钟机械相减以估计纯开销。全套正式实验仍需统一、预声明的计时顺序和资源条件。

## 每次调用及恢复成本

`measured_coordinator.MeasuredCoordinator` 在原协调器外记录每个逻辑任务的追加式调用。`run`、显式 `retry`、资源拒绝、异常和零重算验证分别保留。计时边界包围完整协调器调用，含其中的登记、恢复、进程生命周期、封存及历史核对；记录器自身写盘、报告查询和调用间等待不包含在内，也没有被隐去地并入另一个阶段。

只读 `read_calls` 与 `summarize_calls` 将调用回执和已有尝试历史对应起来。若某个实际尝试没有完整外层计时、或某次调用有开始记录但没有结束记录，总耗时为未知；仍保留所有已知消耗。不根据壁钟时间戳推算丢失耗时，不用成功重试或很短的恢复检查覆盖原耗时。调用结果只能对应已登记尝试，重复的实际执行身份被拒绝。未完成调用记录本身不证明进程已经停止；原生进程组观察仍由既有协调器负责。

本次预声明人工故障：真实 G1 顺序 MALA 已完成普通计算和独立审计后，工作程序主动以7退出。外层因此将原任务封存为 `interrupted`、`samples_eligible=false`。在确认自建进程组消失后，显式重试相同源码、配置和实际输入；没有把原任务直接改成成功。此场景验证的是一个确定的故障位置，不能推及任意时刻的监督进程崩溃或逃逸子进程。

| 记录 | 实测耗时 |
|---|---:|
| 原中断调用 | 2.890947秒 |
| 含显式恢复与重试的调用 | 2.831256秒 |

| 后续零重算验证调用 | 0.008027秒 |

恢复前后原参数、无约束数组及接受事件完全一致。原26个文件保留；五个逻辑任务的实际恢复检查新增执行0，120个原/重试任务文件保持不变。后续验证调用单列，不替换原来的执行成本。任意多次人工恢复检查的合计不是标准化的推断达标时间；正式协议需要固定调用和恢复政策。

四组缓存验证16次，加故障原始及恢复2次，共18次真实 MH 执行；**新增独立统计重复0**。短链的科学诊断及历史失败并未因本轮工程核验改变。
