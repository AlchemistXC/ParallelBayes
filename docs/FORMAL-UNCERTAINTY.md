# 正式分析基础：完整重复配对、区间与成本

2026-10-05。实现提交 `fca9605bafac345a09621bf8d1e52c8eaf40106b`。本工作关闭[F3设计草案](F3-FORMAL-DESIGN-DRAFT.md)中配对不确定性基础接口的开发检查；正式原始数组提取、流式诊断和运行器仍未完成，正式协议未冻结。

## 实现范围

`scripts/completion/formal_uncertainty.py` 提供五个公开入口：

| 接口 | 行为 |
|---|---|
| `create_plan` | 为一个目标的完整四链重复生成实际重采样索引；重复ID有序且唯一，单计划数组不超过64MiB |
| `save_plan`／`load_plan` | 新目录一次性保存索引和身份，校验容器哈希、实际数组及声明身份的确定性重建；拒绝覆盖 |
| `analyze_function` | 多工作流／预算共享同一索引，计算条件误差、共同有效配对差及逐项BCa区间 |
| `analyze_costs` | 分离有效输出、数值失败、基础设施中断和未运行；保留全部已记录耗时，计算条件配对成本比 |

独立单位始终是完整四链重复。输入要求每个工作流明确列出所有计划重复ID，缺失估计用`None`；不能删掉失败ID后重新编号。函数、预算和成本复用同目标计划，不分别重新抽索引。NUTS与MH只是重复身份配对，不声称共享转移路径。

区间采用9,999次整体重复重采样和双侧95% BCa；jackknife也删除完整重复，包括失败行。运算按最多64个重采样索引批处理；单次处理一个函数，输出标量报告与可另存的bootstrap数组。此处有界处理的是摘要层，不替代正式原始轨迹分析器的流式内存验收。

至少20个有效／共同有效重复才计算条件区间；常量经验损失、不可用分母、退化jackknife、奇异BCa变换或零宽界限保持不可判定。记录BCa偏差修正、加速度、调整分位数及尾部有效顺序统计量数量；不在退化时悄悄改用另一方法。区间仅逐项、条件于所给参考，不声称同时覆盖或一般收敛。BCa及配对行为参照 [SciPy 1.15.3公开接口](https://docs.scipy.org/doc/scipy-1.15.3/reference/generated/scipy.stats.bootstrap.html)，实际比较通过该接口完成，不调用其私有BCa函数作为待测实现。

解析真值、有限MCMC参考、未认证积分和未定参考沿用前一接口区分。`formal_error_summary.py`另补充平方损失／参考敏感性溢出保护；保留观测估计，误差字段不可用，不以崩溃终止其他单元或把溢出变成零损失。±2MCSE仍只是参考移动敏感性，不能解释为传播了参考不确定性的区间。

成本报告给出所有已记录任务的总消耗、无可用输出任务的消耗、记录条件均值，以及有完整记录时的全计划均值。成对成本比较为共同数值有效重复上的 **A耗时/B耗时的几何均值**，在对数比尺度计算BCa后转换；不是“均值之比”，也不是既有图表的中位速度比。常量比仍报告点值但不输出已知零不确定性的区间。共同有效重复中有缺失或零成本时，比例保持不可用，不把这些重复悄悄剔除。基础设施中断或未运行使整体科学失败率暂不可判定；全部已科学分类时，另给逐项Clopper–Pearson二项区间。

## 实际核验

按TDD分别实施四个接口行为检查，保留每次红灯与绿灯日志：

1. 完整数据的单方法损失、配对损失差及实际bootstrap统计数组，与独立SciPy公开实现一致。
2. 有缺失输出时，按重复ID对齐而非字典插入顺序；共同有效四格数为28/6/6/0。保存、读回计划后仍与SciPy配对结果一致，另一函数复用同一索引。
3. 未定参考、常量输出、少于20次及极大有限估计导致的平方溢出均保持明确不可判定状态。
4. 失败运行耗时保留；共同有效成本比与独立SciPy对数比区间一致。技术样例A总消耗918秒、失败消耗400秒，B分别817.4秒、200秒；这些是手工构造测试数值，**不是实验性能结果**。

四项新检查通过；修改误差汇总时又运行已有三项受影响检查并通过，不将它们重复计为新测试。检查使用Python3.12.14、NumPy2.2.6、SciPy1.15.3、pytest8.4.2。没有修改冻结采样器或R诊断实现，没有新增MCMC。
