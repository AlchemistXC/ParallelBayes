## 方法与误差范围

令q=c+Lz，其中c为解析NumPy梯度的数值驻点，L为该点负Hessian逆矩阵的Cholesky因子。驻点求解从(0,0)出发，12次函数求值后最大梯度分量约8.68e-14；c约(0.60595936,-0.62188193)。这一坐标选择只帮助积分，不是新的后验近似。固定坐标的Jacobian为常数，在后验函数积分之比中抵消；输出normalizer_z_scaled不是模型证据或边际似然。

在z空间方形[-R,R]^2上采用张量Gauss–Legendre规则，R取6、8、10、12，每维阶数取32、64、96。每批最多128个点，完整12组均保存。六个连续函数直接积分；beta>0按半平面边界改变第二维积分下限，并在边界与方形相交处切分第一维区间。因此稀有事件没有被当作节点上的粗糙0/1网格计数。

为检查有限范围之外的贡献，使用logistic对数似然的全局凹性。令h(z)=log L(c+Lz)-log L(c)，在第j个角扇区中心u_j、半径R处计算梯度g_j，定义

\[
 b_j=h(Ru_j)-g_j^T Ru_j,\qquad
 \kappa_j=-\max_{u\text{ 位于该扇区}}g_j^Tu.
\]

全局支撑平面给出h(ru)不超过b_j-kappa_j r。此次256个扇区均满足kappa_j>0。方形遗漏区域包含于圆盘外部，因此遗漏的未归一化质量不超过

\[
 \sum_j \Delta\theta\,e^{b_j-\kappa_jR}
 \left(\frac{R}{\kappa_j}+\frac{1}{\kappa_j^2}\right).
\]

一、二阶矩使用|q_i|不超过|c_i|+||L_i||r再积分相应多项式；预测概率和事件函数均不超过1。界的推导适用于该对数凹目标，工具没有声称它适用于任意后验。解析高斯目标的矩、旋转半平面概率、精确圆盘尾质量，以及无衰减时明确失败，均通过新工具的3项测试。

**尾界用普通浮点运算求值；内部积分也未采用区间算术。** 下列结果提供网格/范围稳定性和尾部贡献检查，不是经认证的总数值误差上界，也不是解析真值。浮点尾界极小不意味着所有计算都精确到同样位数。

选择R=12、96阶是分析前规定的规则，未依据与MCMC接近程度挑选。R=12的32阶规则仍有约2.10e-7的连续均值差异（相对最后规则的最大绝对差），说明仅扩大范围并不保证离散化充分；这一较粗规则未删除。R=12的64→96阶事件概率变化约1.77e-24，R=10→12的96阶变化约4.76e-24。这里的接近程度是数值稳定性证据，不能单独证明误差上界。

## 与有限MCMC参考的比较

MCSE单位列为(MCMC均值−积分均值)/已报告最大MCSE，是描述性尺度，不是z检验或置信覆盖证明。

| 函数 | 独立积分均值 | MCMC均值 | 差异／MCSE |
|---|---:|---:|---:|
| alpha | 0.606577111764 | 0.6067102479 | 0.210 |
| beta | -0.622983249526 | -0.622143444 | 0.811 |
| alpha_squared | 0.371577055107 | 0.371713306195 | 0.178 |
| beta_squared | 0.397618707774 | 0.396531180996 | -0.804 |
| p_switch_0m | 0.647037397034 | 0.647068743992 | 0.217 |
| p_switch_100m | 0.495902581171 | 0.496145549399 | 1.538 |
| beta_positive | 4.76720875655e-11 | 0 | 未确定 |

六个连续函数的差异约0.18–1.54个所报告MCSE，与有限参考的误差尺度相容；不能据此排除所有MCMC共同偏差。beta>0得到约4.77e-11的非零数值概率，与一万个保存值中没有正事件相容；没有据此构造独立二项界或证明MCMC正确。

原有限MCMC参考的事件MCSE、Rhat、ESS仍为未确定，不用积分值将常量链诊断改成理想收敛。后续推断协议若使用这个事件，必须显式说明采用数值积分参考及其误差限制、事先设定误差尺度，并避免把“绝大多数时候输出零”误写成探索尾部的证据。历史L2的参考不确定性与本案例不同，仍单独保留。
