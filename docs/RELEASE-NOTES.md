# 本地发布候选与冻结结果

0.1.0完成了原始CPU开发核验，并作为protocol-v1的正式采样实现冻结。原源码位于`execution/source-snapshots/formal-v1-source.tar.gz`，所有原始结果继续保留。

0.1.1是审查修订版，修复约束输出溢出或正值下溢、失败轨迹覆盖、部分末窗口停止、恢复环境记录及一维R向量序列化。任意Stan模型无法执行独立轨迹核验时会明确拒绝`audit=TRUE`。原生算法目标、步长约定和接受规则未改变。完整补丁随交接包保存。

历史GPU交接采用新协议版本，不能静默将旧CPU结果改名为新版本性能。主文CPU图表对应0.1.0实测；新版正确性、包检查和SBC单独列出。源码不同的CPU/GPU结果可以各自做同机同核比较，不用于纯硬件加速比。

原始核心依赖锁保留，审查版另外锁定33个Python传递依赖，以及15个CUDA候选包。CUDA组合已通过依赖解析，实机支持仍未确认。完整pip解析清单和下载文件校验和存于`environment/locks`。

正式SBC采用statistical-v4，与未执行v2的数据及采样种子相同，增加成功输出的诊断保留并对应0.1.1源码。开发12组SBC、正式64组SBC和CPU正式1920任务为不同的证据层，不混作独立重复。

本机交付已完成：1920正式任务和320正式SBC拟合全部保存；58项Python测试、R包检查和安装后端到端案例通过。数值摘要已从原始输出重建核对，中文软件稿初版编译为13页PDF并完成视觉检查。CPU组中位数未见时间并行加速，未据此改变冻结配置。L2参考不确定性、NUTS发散和有限SBC功效均保留。

0.1.1-rc2 GPU交接补充文档、R示例和拟合前预先规定的SBC伴随分析，不改变rc1内核指纹或GPU protocol-v3；该历史路线现已暂缓，不适用于用户要求的原生Windows GPU。
