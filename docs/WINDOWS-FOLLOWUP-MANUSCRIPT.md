新增机制表和沿用原矢量图列出全部120个时间执行配置：CPU/CUDA各24个quasi-DEER配置均较慢，Picard各36个配置中20/32个缓存比值大于1。每模型只有两份独立实际输入；三次缓存重放、窗口变体和跨设备副本不扩充n。192个工作流的960份保存路径独立重放零接受事件失配。每端6个零接受工作流保留。

从全部等512输出记录计算8个预设配置对照：16条32步顺序链都快于单条512步、窗口16的Picard，后者时间是前者的4.43–6.92倍。此描述是本轮从保存CSV补充的分析；输入角色和比较配置来自已冻结机制协议，不追溯声称该描述曾预先发表。路径长度和初始化份数不同，不能解释为相同精度的推断优势。

MALA/quasi-DEER的映射与JVP增量及Picard的自环前缀提供成本解释；计数不是等价FLOPs，重叠探针不做可加的独占耗时分解。27主任务、24缓存探测/96调用和新环境安装属于技术验收。59/90条函数诊断Rhat>1.01、27条tail ESS未判定继续呈现。正式适配器v2实机验收、共同精度实验和最终投稿稿仍未完成。
