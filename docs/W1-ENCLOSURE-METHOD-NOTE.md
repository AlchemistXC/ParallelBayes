# W1认证计算的方法资格

2026-10-10。开发记录，尚未对W1七函数宣布认证。新独立环境保留历史环境不变，使用python-flint 0.9.0的Arb球算术。

有限矩形上的两种独立组织为张量二点Gauss和张量Simpson。对宽度hx、hy，逐函数余项分别取

E ≤ hy hx^5 Mxxxx/C + hx hy^5 Myyyy/C，

其中M是整个矩形上四阶纯偏导绝对值的可靠上界，Gauss二点C=4320、Simpson C=2880。由Iy(Ex)+Qx(Ey)分解及正权重求和得到二维界，不需要把两种规则的差当作误差估计。节点、权重、函数值和偏导包络都用球算术；区间分割端点使用精确二进制值。依据：[NIST DLMF 3.5的Gauss与Simpson余项](https://dlmf.nist.gov/3.5)、[Arb数据与舍入接口](https://python-flint.readthedocs.io/en/latest/arb.html)。

实现维护节点求积和已给定的余项上界之和；替换父单元时移除父余项，不把其区间半径重复加入。检查点的球区间含舍入误差。规则资格涵盖四次多项式的已知积分、二维高斯有限域与半空间、遗漏余项和尾部的错误注入，以及工作上限下宽包络的保留。

这一步仅验证有限矩形积分组件；W1仍需专用目标与四阶偏导、尾部质量及矩包络、事件区域划分、正归一化下界和比率区间。有限测试不替代这些数学条件。两种组织使用共同函数/偏导，因此不能把两者吻合当作独立无误证明。

组件资格现已通过8项检查（0失败、0跳过，警告作为错误处理）。首次二维高斯检查的两项失败源于跨零区间的通用幂运算返回非有限值，现使用明确的整数乘法；最小二进制单元无法继续分割时保留原单元和宽包络。此记录不表示W1七函数已获认证。
