# W1独立核验与参考敏感性

2026-10-10。已实现终态核验器并完成13项针对性检查。正式积分仍在原会话运行，目前没有最终W1认证结论。本文件补充[原方法资格](W1-ENCLOSURE-METHOD-NOTE.md)，不修改冻结协议或计算源码。

## 核验器检查什么

`scripts/analysis/audit_w1_enclosure.py`只使用Python标准库，既不调用Arb，也不调用原积分、后验比率和报告函数。它读取保存的二进制球区间：中点m×2^e和半径r×2^s，以Fraction形成精确有理端点。JSON中的浮点显示值不用于认证判断。

1. 核对固定协议SHA、原数值源码SHA、目标身份、全部终态资产及方法/探测侧车校验和；确认运行锁已释放。未产生SUMMARY/checksums或仍被写入的结果不能作为已完成输入。
2. 只读打开已结算的SQLite。每个活动单元的端点球中寻找可复核的二分坐标，检查其仍在原区域内。沿每条竖边精确累加覆盖次数的变化：内部变化必须抵消，外边界必须对应覆盖一次；总面积也必须一致。这可以发现面积相同但局部重叠/缺失的分区。
3. 从全部叶单元重新求和求积区间与余项上界。保存的增量累计区间必须包含该结果；不能只检查两套最终小数接近。两个域的分界使用原二进制中心/矩阵的精确比值−cβ/A22，球端点的不确定性不会通过转成double消失。
4. 独立加入质量、一阶绝对矩和二阶矩尾界。非负量与[0,∞)相交；有符号分子加入对称尾界。只有归一化常数下界严格为正时才做四个端点的比率运算。
5. 保存的后验球必须包含上述有理数结果；两规则求交的保存结果须包含精确交集。逐函数重新判断半宽及事件相对半宽，并核对任务终点、积分单元、回调和已预留工作次数。宽但有效区间不被标为精度达标。

本检查不重新评价被积函数，因此新增目标/导数评价为0。独立性限于端点、分区、汇总与比率；实际函数、导数和尾界仍依赖下述数学条件和先前组件资格，不能把核验器通过扩大成一般软件无误证明。

## 与固定实现逐项对应的数学条件

令θ=c+Az，J=|det A|，g(z)=J exp{ℓ(c+Az)−ℓ(c)}。分子和分母采用同一缩放。实际目标使用原3020条观测的binary64距离/100和结局；变换常数也按原binary64值精确解释，不要求c恰是真众数。

**有限域。** 对每个光滑积分分量，张量规则的误差分解为Iy(Ix−Qx)+(Iy−Qy)Qx。正权重的和等于区间长度，因而纯四阶偏导上界给出hy hx^5 Mxxxx/C + hx hy^5 Myyyy/C；两点Gauss取C=4320，Simpson取C=2880。后一常数由[一维Simpson余项](https://dlmf.nist.gov/3.5.E6)的半区间步长换算，Gauss依据[高斯求积余项](https://dlmf.nist.gov/3.5.v)。这是绝对余项界，不是两种规则差的经验估计。

固定代码通过logistic的四阶方向导数和乘积法则包络七个连续被积函数。ℓ为凹函数，矩形中点的支持平面给出整个矩形上的密度上界；导数区间包含所有矩形内参数。即使区间乘积较宽，也不能将其窄化为点值。事件I(β>0)不求导：上三角A使事件边界只依赖第二积分坐标，事件积分使用正侧区域的密度分量。

**尾部。** 在半径R的每个角扇区中心方向u上，记白化坐标梯度的径向/切向分量为a<0、b，角半宽为δ。凹性支持平面及κ=−(a cosδ+|b| sinδ)>0给出g(ruφ)≤J exp(C−κr)，C=ℓ(c+ARu)−ℓ(c)−Ra。乘极坐标Jacobian r后对r≥R积分。矩界另使用|θj|≤|cj|+||Aj||r，分别积分r、r²、r³项；质量尾界不能直接冒充矩尾界。圆盘外区域包含方形外遗漏区域，故该界保守。全局归一化、两项预测概率和正侧事件的尾项使用相应界。

**算术。** 原计算的节点、函数、导数和误差包络使用384-bit球算术；各运算应保持向外包络。[python-flint的Arb接口](https://python-flint.readthedocs.io/en/latest/arb.html)定义中点/半径表示；独立核验器从保存的二进制表示直接还原端点，避免第二次半径舍入。有限测试和两规则一致仍不取代上述条件。

## 参考区间怎样传播到原比较

给定参考区间[l,u]，单方法的平均平方差在样本均值投影到[l,u]的位置最小，在端点之一最大。两个方法共享参考时，配对损失差是参考c的仿射函数：

D(c)=mean(A²−B²)−2c mean(A−B)。

所以取l/u两端即可得到完整范围，而不是把两个独立MSE区间相减，后者会丢掉共同参考的抵消。脚本使用保存函数均值的精确binary64有理值，原额外尺度s_f=1；每对方法仅使用原共同有效重复，计划分母和失败均保留。七函数×十八方法预算格给出126行单方法范围；两个预算内全部九工作流的成对组合给出504行描述性范围。原参考点的损失另列。

范围不跨0只说明这些保存估计的点排序未被该数值参考区间改变。原重复实验的BCa区间和有限重复不确定性继续另报；本分析不计算新显著性、不选择有利配对，也不更新历史达标率。
