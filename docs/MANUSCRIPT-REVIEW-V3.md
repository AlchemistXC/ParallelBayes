## 复算入口

从固定源码根目录执行，输出目录须不存在：

```sh
python3 scripts/analysis/review3_numerics.py \
 --root . --inputs benchmark/analysis/outputs/manuscript-review-v3/inputs \
 --output output/new-review3-numerics

python3 scripts/analysis/write_targeted_followups_tex.py \
 --root . --manifest manuscript/software/targeted-inputs.json \
 --templates manuscript/software --output output/new-targeted-text

python3 scripts/analysis/write_nuts_localization_tex.py \
 --root benchmark/analysis/outputs/nuts-mac-intake-v1 \
 --templates manuscript/software --output output/new-nuts-text
```

API示例选择既有锁定torch Python和R安装库后，从任意目录运行：

```sh
Rscript --vanilla examples/paper-api.R output/new-public-api-example
```

设置R_LIBS_USER和RETICULATE_PYTHON是在启动R前选择环境，不是现场下载升级依赖。脚本拒绝已存在输出，先保存两份完整fit和状态，再检查输出；失败仍可读取记录。paper-api的含审计采样接口时间不冒充正式普通工作流费用。
