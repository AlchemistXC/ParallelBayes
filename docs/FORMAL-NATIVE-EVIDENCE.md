## 读取接口

`scripts/completion/formal_native_evidence.py::read_native_task` 接收归档根目录、冻结任务和源哈希、单任务导出历史、结果目录、交付清单和可选外层调用账本。旧 Windows 绝对路径只用于核对历史身份；所有文件读取均使用显式归档相对路径。因此可在 Mac 读取搬移后的材料，不调用 Windows API，不读取或修改原机器的活动任务数据库。

它核对任务事件链、实现绑定、每次尝试的顺序与文件、终态记录、相应 Job 名称与原记录中的终止观察。后验、缓存测量、数值失败、资源失败、未分类输出失败和基础设施中断分别保留。注册后尚未启动的任务为 not_run；缺失历史导出是证据缺口，不能据此填写 not_run。未解决的 active 记录会被拒绝，须在原主机按原源码处理后重新导出。

中断后保存的数值失败不能改称可重试的基础设施中断。只接受至多一次后验基础设施重试，缓存不重试；旧未知时间继续为 null。外层账本仍复用原成本政策，普通子进程、研究执行、额外核验与全部调用时间分别报告，不将嵌套时间相加。没有账本时不估算外层时间。

`formal_acceptance.py` 复用此读取接口，继续要求预声明的 27 主任务、24 缓存任务及 16 原生行为用例全部符合既定验收要求。它不会把本地文件测试当作原生验收记录，也不会据 `passed=true` 单字段授权正式执行。
