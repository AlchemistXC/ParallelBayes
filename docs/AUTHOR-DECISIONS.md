# 投稿前需要作者确认的事项

2026-10-11，submission-v4-rc1。以下是作者决策，不是尚未完成的计算任务。候选封存保留作者占位；收到确认后生成后继版本，不覆盖本候选。

| 项目 | 需要提供或决定的内容 | 对后续工作的影响 |
|---|---|---|
| 署名与单位 | 作者姓名及顺序、单位/地址、通讯作者邮箱、ORCID（如有）、贡献分工 | 替换正文和软件维护者占位；不从Git提交身份推断学术署名 |
| 资助和利益冲突 | 项目/基金名称及编号；是否存在利益冲突；致谢对象 | 完成稿件声明 |
| 原始材料的分享范围 | 41组件清单中哪些允许公开，哪些仅供审稿；现有草稿是否继续保持私有；H1/L2/W1本地原件是否可上传到选定受控位置 | 决定实际数据入口；现有“允许追加到草稿”的授权不等于允许公开全部草稿 |
| 数据权利及许可 | 第一方生成数组的分享条款；机构/资助方要求；posteriordb水井数据沿用原来源与适用条款 | 不把代码MIT许可自动扩展到第三方数据或全部原始科学数组；不虚构限制理由 |
| 审稿访问方式 | 公开固定归档，或目标期刊接受的受控/匿名链接；联系人和实际获取流程 | 才能完成非作者账号的访问验收；不能把GitHub draft URL当匿名审稿链接 |
| 期刊与语言 | 目标期刊/备选、文章类型、是否需英文稿、匿名审稿要求 | 再按当时官方要求调整模板、篇幅和投稿材料；当前中文研究稿不自动视为该期刊终稿 |
| AI使用与最终责任 | 确认目前辅助代码/分析组织/图文的使用披露；机构与期刊是否有额外要求 | 按目标政策如实说明，作者负责终审，不把生成工具列为作者 |
| 最终批准 | 阅读正文、SI、失败/不确定性边界和材料清单；批准用于投稿的后继封存版 | 本项目不自动提交期刊、CRAN或公开数据 |

不需要作者为了结项确认“所有算法都收敛”“CPU/GPU普遍加速”或“105历史故障全部修复”。这些均不是本论文已建立的命题。

中文核对：署名、邮箱、资助/冲突、数据许可及公开范围、审稿入口、期刊/语言均待真实信息。DOI、伦理审批号或机构授权不得补造。
