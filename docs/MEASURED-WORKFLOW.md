# 普通推断过程与外层研究审计的独立计时

2026-10-05。采样与测量源码 `eac65b50444729ba061bacfa190f8a0fd00119c3`；协议与只读归档重建源码 `8d15d579620bf4d21882fc0ef0b8caf5faf80439`。这是有限 Mac 技术验证，**不属于正式推断实验或新性能结论**。沿用现有测试与统计报告约束，不修改历史采样代码、协议、输入或容差。

## 实际测量了什么

原 MH 接口把 NumPy 独立路径核验放在采样调用内部。直接用总时间减去其中的核验计时，只能得到嵌套阶段小计，不能证明一个独立普通工作流的真实延迟。

本次新增三个模块：`measured_ordinary_worker.py` 在独立子进程完成普通批量计算，MH 使用既有 `audit=False` 路径；`measured_audit_worker.py` 等该进程退出后，用相同原始随机数组和原标准进行独立核验；`measured_workflow.py` 提供子进程计时及不修改候选数组的核验决定。外层仍使用已有协调登记、进程组及采样内存保护。

| 口径 | 测量边界与包含内容 | 本次状态 |
|---|---|---|
| 缓存执行 | 已准备的数值内核实际执行，需单独同步和重放设计 | **未独立测量**；不能拿现有嵌套 sample 计时替代 |
| 普通过程 | 创建子进程前至其退出；包含 Python/数值依赖导入、目标和输入核对、采样、变换、完整数组输出、函数与 R 诊断、退出 | 五工作流实际测量 |
| 含审计任务调用 | 外部调用 `TaskCoordinator.run` 前至返回；包含登记、资源检查、工作进程生命周期、普通过程、独立审计、封存与历史核对 | 五工作流实际测量；自身计时回执写入及随后伴随验证不在边界内 |

这三种口径相互包含，不能相加。普通子进程内的采样、输出与诊断阶段另存不重叠日志；日志写盘及阶段间间隙不包含在阶段和中。审计阶段包含审计依赖加载、目标重建、读盘和核验，并非纯 NumPy 递推时间。NUTS 使用真实四进程 CPU 工作流，父进程池墙钟包含启动、预热、IPC 和退出，不将并发子链耗时相加。

本次普通输出策略保留原/无约束路径、接受事件，以及 NUTS 预热/调参记录。它是明示的 Python 批量使用口径，**不是最小 R 前端延迟，也没有清空操作系统文件缓存**。普通进程写出的 `ordinary-output.json` 始终 `samples_eligible=false`；只有外层独立核验通过，封存的 `worker-result.json` 才为有效研究输出。原 `candidate.json`、`fit.npz` 保持原样。候选模型/配置/实际输入身份不一致、接受事件或轨迹不合格时均不得放行。

## 冻结的技术验证与结果

新协议 `measured-workflow-technical-mac-v1` 的 SHA256 为 `8f8ac5a0b31260a958a63ef723b7ea56768d12a9b02790509a19aae20ab135f2`。复用原 `formal-runtime-technical-mac-v1` 中 G1 的四种 MH 工作流和 L1 的四进程 NUTS；MH 各链 80 步、丢弃前 16 步，NUTS 预热 32、保留 64，四链。新执行五次，**新增独立统计重复为零**。

| 技术工作流 | 普通过程实测秒数 | 含审计调用实测秒数 | 独立审计阶段秒数（已包含在外层） |
|---|---:|---:|---:|
| G1 顺序 RWM | 1.307035 | 2.344785 | 0.751728 |
| G1 顺序 MALA | 1.896064 | 2.874444 | 0.730003 |
| G1 Online Picard | 1.334735 | 2.311963 | 0.731608 |
| G1 quasi-DEER | 2.178642 | 3.129742 | 0.682328 |
| L1 四进程 NUTS | 2.471140 | 3.442421 | 0.717186 |

每项仅一次技术执行，顺序固定，未进行交错重复或性能区间估计，表格只说明计时边界实测成立，不能用它排序算法或声称加速。NUTS 的审计为形状、有限性、变换及实际初值/种子核查，不声称与 MH 同轨迹或证明后验收敛。

实际验收：五项完成；四项 MH 独立核验通过；两组同核配对的接受事件均零失配。两组最大路径差分别约 `8.882e-16`（RWM）和 `2.666e-10`（MALA），均在原标准内。每一工作流与**其自身旧版**保存的原参数、无约束数组及 MH 接受数组完全相同；这里的“完全相同”不能误解为顺序与时间执行彼此逐位相同。

五份函数传输字节、R 回写和保存现代诊断均与各自旧记录一致。16 行函数诊断中仍有 **10 个有限 Rhat>1.01**，不可判定 0；技术输出通过不能等同于有效探索。实际零重算恢复通过，143 个任务文件及初次计时回执保持不变；恢复验证耗时单独记录，不能覆盖初次执行耗时。

两项新增行为检查通过：独立审计不修改候选、错误轨迹被隔离，以及真实子进程退出码/计时/日志保留。首个模块缺失红灯和后续日志均保留；没有将重复测试累计为更多覆盖。旧预算协议 58 份、旧技术协议 65 份以及本协议 10 份源码哈希均一致。
