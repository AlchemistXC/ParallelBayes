## 改变了什么

旧预算分析器同时缓存所有目标的随机输入和不同配置的路径前缀，不能直接扩展到正式设计规模。新流程保留旧程序及其结果，用独立入口逐任务读取输入和轨迹。每项核对协议、源码、原任务状态及资产哈希、实际随机数组、初值、MH审计或NUTS工作进程记录、原参数变换和保留步数，再重新生成函数、R二进制传输与现代诊断。

`formal_streaming.extract_functions` 在分配数组之前检查NPZ成员声明的尺寸和类型，默认每个数组成员不超过128MiB。一次只处理一个拟合；参数变换按128步块核对。跨预算前缀只保留形状、类型和实际数组字节的SHA256，不保存全部旧轨迹；不相等时只报告字节不一致，不虚构最大数值差。

`aggregate_model` 一次处理一个模型的标量记录，并调用已核验的完整四链重复配对／不确定性接口。必须包含所有预定工作流、预算和重复身份；失败使用显式缺失值，不能删除后重新编号。不同函数和预算共用同一份实际重采样计划。每个模型4次独立重复不会因bootstrap而增加。

`analyze_budget_streaming.py` 是**历史预算pilot格式的适配器**，明确拒绝其他协议身份。它保留少量旧标量作为对照，不缓存全实验原始数组。正式运行器格式、资源失败分类、中断恢复及正式最大任务验收仍需补齐，不能把此入口直接改参数后称为正式全网格分析。

## 内存与耗时边界

实际重建约124.10秒。Python进程生命周期峰值RSS为147,734,528字节（约140.89MiB）；最大子进程生命周期峰值为188,661,760字节（约179.92MiB）。两者分别由系统记录，**不是同一时刻的进程树总RSS，不能相加作为实测总内存**。此数据只描述同一Mac、现有依赖和当前pilot；不能证明Windows或正式最大任务已通过资源验收。

本次重建时间是分析程序成本，不是采样性能数据。旧任务墙钟仍缺少后来R诊断及部分终态哈希成本；重建不能补造历史正常推断或完整审计的实测时间。
