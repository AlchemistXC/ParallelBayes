# L2 独立稀有事件参考的方法

2026-10-10。对应三项补充计划S3B。资格阶段已通过，实际L2六个确定点的对数目标已与128-bit Arb标量公式核对；未把数值相符称为一般证明。独立高斯目标验证了提议常数、截断条件分布、概率和归一化常数；实际随机数组及权重分块的恢复/篡改检查通过。

目标为原始八参数L2 logistic模型的第一坐标大于零的后验概率。读取原冻结协议中的实际X、y和N(0,2.5²)先验，数据文件与目标标识绑定；不重新生成数据，不使用仿射采样坐标。原262144个相关参考样本及恒零事件不改写。

提议为0.45多元t（自由度5）、0.45事件域截断多元正态、0.10原先验。每个点独立随机选组件，计算完整混合密度。截断正态先抽第一坐标的正半轴截断边缘，再抽其余坐标的条件正态，不做裁剪。无约束众数与事件约束众数均用独立NumPy/SciPy目标，最大1000次迭代；保存收敛和信息矩阵谱。特征值下限为max(1e−12,最大特征值×1e−10)。事件众数在边界且目标斜率向外时，将第一坐标标准差取为原局部标准差与斜率倒数之较小者，保持其他坐标的条件协方差和回归系数。

四组试探标准差倍数固定为(1,1)、(1.5,0.5)、(2,0.25)、(3,0.125)，分别作用于t和事件正态的协方差平方尺度。每组4096点；按比率影响量的相对方差估计从小到大选择两组，平局按编号，试探全部排除。正式生成前写入不可覆盖的SELECTION.json。

两套提议分别运行8个独立PCG64批次，每批131072点，共2097152个正式参考点；含试探总上限2113536。每批先保存全部实际提议、组件和生成前后RNG状态，再以256点计算目标、8192点保存权重。预定8192、32768、131072处记录质量，但不按精度提前终止。恢复核对协议、源码、依赖、参数数组及权重哈希，不重新生成已有随机点。

每套提议报告总分子/总分母的自归一化比率，MCSE由8批(A,B)的联合协方差及delta方法计算；不平均批次比率。分别报告分子与分母ESS、最大归一化权重和各批次原始量。相对MCSE≤10%、事件ESS≥200、分母ESS≥1000、最大事件权重≤0.05、分母权重≤0.01为预设质量目标；两套概率的差不超过3倍合并MCSE只是相容性检查。有限样本偏差和近似MCSE仍存在，不能称为严格认证。

每个冻结执行需独立环境，依赖锁见execution/targeted-followups-v1/qualification/requirements-mac-followups.txt。Mac矩阵乘法曾出现非有限警告但结果数组有限，现以明确einsum实现对应运算并以警告即错误模式验证；未静默压制警告。线程环境固定为OPENBLAS_NUM_THREADS=1、VECLIB_MAXIMUM_THREADS=1。计时仅为参考计算工作记录，不作为采样速度结果。新增工作≤3 GiB、进程RSS≤4 GiB、启动/检查可用空间≥10 GiB；无总时长截止。

运行入口为scripts/analysis/run_l2_importance.py。先提交源文件，再freeze生成benchmark/protocols/l2-rare-reference-is-v1.json，之后使用该协议run到独立output目录。正式结果产生后另建结果报告；本文件不预写概率或达标结论。
