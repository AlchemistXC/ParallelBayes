### Windows 执行方式与新增对照

主网格使用原生 Windows PyTorch eager、float64，CPU 与 RTX 5080 独占错时运行。顺序 RWM/MALA 与对应的 Online Picard RWM、quasi-DEER MALA 使用相同的转移定义和数值目标。冻结时记录本次 Windows/Python/PyTorch/CUDA、驱动与设备版本。Mac 的 JAX/BlackJAX/Diffrax 承担独立参考。旧环境的 eager 回执仅覆盖已测目标。

1. **同平台 NUTS。** Windows CPU 上对正式分层 logistic 和真实 ODE 分别跑 1024、4096 步，每格 32 份，共 128 次四链执行。采用 Pyro NUTS，四个进程各一链、每进程一 CPU 线程，每链适应 1024 步；对角质量矩阵、目标接受率 0.8、最大树深 8 在代理上检验后冻结。独立 NUTS 随机流，共享数据、目标和可比的初值块。绕开旧版高内存诊断调用，交付样本给相同的 R 诊断流程。正式运行前，两模型的代理各用三份 4096 步输入实测四进程交付（6 次）。记录发散、树深、实际梯度求值、内存峰值和全部失败。同平台端到端含启动、适应、采样与诊断，列入新模型误差–时间主图；跨核全流程比较也计入 RWM/MALA 取得配置的实际成本。历史 216 次修复另账。
2. **eager/compile 与剖分。** 同一 RTX 5080 上，预定开发域高斯 (d=128,m=256) 和常规合成 ODE，均取 1024 步。顺序 MALA 与 W=32 quasi-DEER 对称比较 eager 和显式 TorchInductor 编译，使用配对输入、相同步长与同步口径。每目标 32 份，各执行方式与后端分别测一次冷启动、一次缓存执行，共 512 次。冷态用独立进程与隔离编译缓存，从首次调用计至交付；热态复用已初始化环境并重置链状态及数组。记录整流程或仅单轮编译、图中断、回落、重编译、前向/JVP/扫描、轮数与推进、主机同步等待和峰值。另在每目标三份资格输入上做带 profiler 的四种组合，共 24 次。普通计时独立于 profiler，重叠 CPU/CUDA 时段分别呈现。接受事件与完整路径通过独立回放后才比较速度。若原生 Windows CUDA 编译失败或仅部分编译，报告失败阶段、实际覆盖、eager 剖分与可支持的归因；保留计划分母。
3. **预热期探测对照。** 常规合成 ODE、CUDA/RWM、1024 步，两臂分别在适应期同步收集探测信息、或在核配置确定后另做短探测。每臂 32 份，共 64 次。预热长度与适应算法预定，探测使用独立流，其结果只决定执行方式。逐对核对预热末状态和最终步长。两臂各计完整外层墙钟，同时报告探测、选窗、回退和采样后段耗时。

**任务量。** 主网格与正式 NUTS 基线共 25984 次；加编译与预热对照 576 次，共 26560 次计划四链执行。另计 24 次技术演练、880 次资格、6 次 NUTS 预检与 24 次带 profiler 调用，共 934 次，以上固定项目小计 27494 次。可选直接配置计时、按规则追加的资格输入、历史 216 次修复、开发探测、四次复用、独立核验与其他辅助资格工作分账。Mac 两模型共 20 条参考链，按单链步数列预算。编译不可用或保护触发时分别列已尝试和未启动数。

### ODE 提议和求解失败

支持集由冻结的模型与坐标变换定义。能证明候选点的目标密度严格为零时，从有效当前状态作合法 MH 拒绝，保留自转移及原因；MALA 可在计算域外反向梯度前短路。在对数采样坐标上的数值溢出、内部步数超限、刚性警告、NaN 或 AD 失败，均不能证明目标密度为零。

域内求值失败按冻结的确定性顺序重算：保持误差标准、提高已验证的内部步数上限，必要时调用事先通过同一精度核验的后备求解器。对同一参数点，当前与候选、顺序与并行、CPU/CUDA 和各窗口位置使用一致规则。MALA 需取得可信的密度、正反向提议所需梯度和提议密度。成功重算按正常 MH 比率处理并计入全部成本；持续求解失败、无效当前状态、程序异常或轨迹核验失败要显式标记并隔离无效输出。NUTS 另按自身积分、发散、求解与交付状态报告。代理资格测试分别覆盖支持集外零密度、域内可恢复失败和域内持续失败。

## 3. 统一揭盲与论文判断

以计划尝试、首次交付、比较配对三张表逐行对账。先锁 N（计划份数）、C（首次完整输出）、M（有效配对计时）、异常处置和分析代码，再一次揭盲。首次调用内合法回退可算完整，外部重跑单列。36 个预定条件（1024 步 24 行，4096 步 12 行）按固定顺序呈现速度比、区间、C/N、M/N、秒数、完整率下界和失败原因。
推荐限于指定条件下观测到的首次使用收益。按相同四链输入比较直接顺序与首次规则：有效配对计时至少 31/32，配对几何平均端到端速度比逐点双侧 95% 区间下限严格 >1.10，数值与封存有效，且缺失机制可解释。若缺失集中于慢调用或回退且无法解释，判为证据不足。每行报告 C/32、失败与回退原因、M/32、尝试成本和连续速度比区间。完整率单侧 95% 精确二项下界只作不确定性描述（32/32 时约 0.911），据此不主张总体完整率达到 95%。分别标注配对不足、速度区间未过线或不可估。只有 CUDA/RWM、1024 步的昂贵留出高斯和真实 ODE 两行均过线才作联合收益推荐；仅过一行时只报告该行。其余描述性预算与四次复用单列。

跨核先比同设备顺序 RWM/MALA，再比完整工作流。每份四链合并产生一个函数估计，按共同有效输入计算平均平方损失差，保留各自有效集、失败、条件均方损失、中位损失及墙钟。预定区间按整份输入重采样 9999 次，逐点 BCa，共同有效重复不足 20 时不报该区间。对于有独立数值参考的函数，参考值为 c 时平均平方损失差 D(c) 随 c 线性变化；共同移动到参考均值 ±2 MCSE 两端，检查是否跨零。两端各作 97.5% 双侧区间，均在同侧才支持对该范围的稳健方向陈述。结论限于预定函数、条件与可用输入。

## 4. Mac 独立参考及测试

分层 logistic 报告总体均值 μ、正尺度组间标准差 τ 和已有 128 组等权平均概率三者的后验期望。真实 ODE 报告雪兔增长率 α 和 1920 年雪兔潜在状态 x(20) 的后验期望。相同参考抽样推导每个函数。MCSE 取链内自相关调整估计与十个链均值标准差/√10 的较大者，各函数不超过其参考后验标准差的 2%，平均概率另须 ≤0.001。到顶仍未达标者保留点估计、MCSE 和原因，限制该函数的误差排序。

每模型十条独立参考链，按先验中央 80% 的分层起点初始化，每链至多四个同层候选；各链预热 1024 步，在保留 1000、2000、4000、8000 步时统一验收。精度不足且仍可依照同一采样器延长时，十链一起进下一档。诊断包括预热后发散、逐参数/函数 R-hat <1.01、能量及按链的树深异常。结构性问题、资源不足和跑满上限仍不精确分别报告。logistic 原则上两链一组，ODE 单链，资格实测才可放宽。参考盲态独立。

## 5. Mac 单机轻量续跑

每条参考链使用一个本地 SQLite 数据库，采用 WAL 与 synchronous=FULL。每 100 个保留步使用一个事务：以 BEGIN IMMEDIATE 取得写入权，核对链身份、环境与输入哈希、最新已提交步和下一 key，然后运行本块。在同一事务内保存样本、诊断、完整 BlackJAX 末状态、步长、逆质量矩阵、下一步号与下一 key 原始字。用链身份和步号作唯一键，记录科学数组形状、精度和 SHA-256。提交后再发运行回执。并发请求取得 SQLite 写锁后重新核对目标步数；已达目标只读验证。异常退出从最后完整事务恢复。交接使用 SQLite 在线备份或经验证的关闭与 WAL 检查点流程，接收端复算摘要。

验收围绕科学输出：固定 key 向量一致；两模型分别比较连续运行与跨进程恢复的 100→300、1000→2000 步轨迹、诊断与下一 key；中断一个未提交事务后核对零缺步、零重号；用另一链的有效库请求恢复须在采样前拒绝。共享逻辑缺陷两模型重验，单一目标或离线汇总问题按依赖重测。持久化与锁管理由 SQLite 提供。
