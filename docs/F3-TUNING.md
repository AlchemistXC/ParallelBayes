# F3独立调参开发与CPU多链基线

2026-10-05。新增调参身份为`inference-tuning-mac-v1`。它与先前就绪验证、后续预算pilot和正式实验分开；没有改写历史Mac/Windows核参数或失败结果。

## 冻结的有限开发设计

- 九目标：G1、G2、A1、L1、L2、H1、H2、M1、W1。几何沿用已核验规则，G2/A1/L1/L2/W1用目标曲率构造的固定Laplace坐标，其余单位坐标。几何不读取参考后验，构造成本另记。
- 两个核均仅用CPU顺序执行调步长。RWM候选为`[0.5,1,1.5,2.4,3.5,5]/sqrt(d)`；MALA候选为`[0.1,0.3,0.6,1,1.6,2.4]/d^(1/3)`。这是预定搜索网格，未声称普适最优。
- 每候选两次独立开发运行，每次4链、512步预热及1024步评分区间，共216个拟合。独立实验单位是一次完整四链运行；链、时间步和不同候选不额外增加独立n。
- 每目标/重复一份实际主输入，18份NPZ的文件和数组哈希冻结；同一重复内的候选与核共享对应初值和实际随机数组。初值在选定坐标中从N(0,4I)生成；M1首坐标预设-5,+5,-5,+5。种子命名空间6251/6252/6253开头，独立于就绪验证及未来正式实验。
- 使用既有torch顺序核和独立NumPy核验，保留全部数组、接受事件、变换、异常和失败。没有自动回退或额外抽样，未达到输出标准的候选不产生有效调参分数。

## 评分及其局限

在选定的固定坐标z中，对预热后的每个转移计算`||z_t-z_(t-1)||²/d`，包括拒绝自环。第一个评分转移使用最后一个预热状态作为前值。每次运行先平均全部4链及1024步；每候选再平均两次完整开发运行。两次均有效的候选才有资格被选，选择最大均分，精确并列时取较小步长；无正分候选则不选择。失败候选及其已完成重复一并保留，不用删失败后的平均数参赛。

这是同核内的局部移动启发式，不是后验误差、跨模态探索或收敛检验；不能用它比较不同核的最终推断优劣，也不按本次运行时间调整分数。预热512步不保证所有目标已平稳。网格边界最优、两次开发运行间分歧及后验诊断均需报告；需要扩展网格时另立开发协议，不静默修改本身份。

所有候选和模型构造成本保留。内部run计时不含Python新进程导入，不能称完整冷启动成本；每次调用有独立日志，恢复不覆盖原调用耗时。最终正式比较还要定义开发成本分摊、逐次预热以及CPU/GPU资源条件。

## CPU多链入口

`inference_parallel_nuts.py`使用真实`spawn`进程，每链独立初值与Pyro随机状态，显式指定进程数和每进程torch线程数。只从已支持的spec重建内置、水井及固定仿射目标，并核对完整目标身份；不反序列化任意模型闭包，不提供Stan转译或GPU NUTS。

父进程池墙钟包含创建/导入、目标重建、预热、采样、IPC及退出；子进程时间可能重叠，不能相加解释父进程耗时。保留实际PID与线程设置，不声称独占物理核心。任何链或身份失败使整份拟合无法返回普通样本，其余子进程结果和错误仍保留。

Mac上的实际双进程测试与串行NUTS路径、原参数输出及初始随机状态逐值一致；另有目标身份错误隔离测试。该证据不验证原生Windows，也尚不覆盖九目标的多进程实测或正式CPU/GPU资源比较。Windows需在自己的新运行身份下接续验证。
