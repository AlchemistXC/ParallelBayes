# 2026年10月12日审读意见逐项审核与v5修改

本轮依据v4正文、补充材料和既有原始结果审核。语言与结构建议大多采纳；统计资格、计时覆盖及故障归因按证据修正，不直接粘贴审读例文。当前以计算实验为主线、软件为研究工具，作者与期刊仍待确定。

已完成正文重写、补充A更新、完整结果补充B的参考类别说明、两张矢量图、216份W1分段记录再分析、两份L1固定轨迹的二进制诊断重算及正式网格之外的R技术示例。技术示例共发生4次采样调用：第一次配对中顺序完成、Picard因默认迭代上限停止；显式上限后两次最终调用均完成。此前另有1次依赖路径错误，在采样前停止。全部日志和失败记录保留。所有原主实验计数、失败、参考和区间保持。未启动新Windows采样。

关键事实：CPU Picard也有7/18组速度比点估计大于1；105项原NUTS失败不能全部归因于旧诊断；L1 ESS差异已定位至相同接受路径的分位数并列值敏感性；v4稀有事件SE源公式已有根号。通过数值核验与充分探索仍是不同检查。
