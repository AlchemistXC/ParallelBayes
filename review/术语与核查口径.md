# 术语与核查口径

核查日期：2026-10-02。使用 `nature-academic-search` 的多来源检索流程、`nature-paper-card` 的证据卡流程及 PDF 阅读工具。

| 统一术语 | 本项目含义 | 不应混用的概念 |
|---|---|---|
| 链并行（chain parallelism） | 同时运行多条链，可共享调参信号 | 单条链更快达到平稳 |
| 数据并行（data parallelism） | 分配似然／梯度计算 | 分块后验合并，后者还涉及统计近似 |
| 模型并行（model parallelism） | 分配参数／模型计算 | 时间并行 |
| 时间并行（time parallelism） | 并行求解同一递推的多个时间位置 | 模型的观测时间序列分块 |
| 预取（prefetching） | 提前计算未来可能分支 | 多候选选出一次新状态 |
| 多候选 MCMC（MP-MCMC） | 每次生成多个候选并按规则选择 | 所有 parallel MCMC；避免把粒子 MCMC 的 PMCMC 缩写混入 |
| 轨迹等价 | 在相同随机输入下恢复顺序递推 | 样本已经平稳、独立或无蒙特卡洛误差 |
| 目标不变性 | 转移核保持目标分布 | 有限运行结果精确等于目标分布 |
| 并行轮数 | 可同步并行的 oracle 调用轮次 | 墙钟时间、总工作量、硬件成本 |
| ESS | 给定估计函数和样本量的有效样本量 | ESS 比率、ESJD、谱隙、独立样本数 |
| 达到指定误差的时间 | 连同预热、调参等，达到定义好的推断精度所需时间 | 任意论文的采样阶段速度比 |

“全文确认”在本轮指通读现有核心来源的正文、已提供附录与补充材料，核对主要结论对应的假设、定理、图表及计算口径。它不等于独立重证全部定理、代码正确性认证或实验复现。发现疑似原文错误时，保留原件，记录精确位置和理由，不直接宣称整篇结论无效。

证据标记：`[Paper]` 为论文原述，`[External]` 为另行核查来源，`[Analysis]` 为本轮分析，`[Hypothesis]` 为待检验设想，`[User]` 为用户构想。精读卡中的 PDF 页码从 1 开始；正式书章的独立 PDF 页码 1–22 对应整书 PDF 588–609、印刷页 569–590。

检索限定于 2026-10-02 及以前可核验的公开记录。检索未命中不等于成果不存在；新增来源的全文阅读程度分别登记。综述价值与新算法的原创性分别评价。
