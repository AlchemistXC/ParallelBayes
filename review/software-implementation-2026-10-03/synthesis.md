# 审查后综合

这是三份报告全部冻结后的独立综合，没有反馈给审查上下文。评估对象是冻结 packet 的软件、方法和协议，不包含尚未完成的正式结果，也不采用 Nature 突破性门槛。

## 共识及分歧

三位审查者都认可目标、转移核与执行器分层，以及共同随机输入、独立重复和诚实的贡献范围。没有人把统一接口看作新采样算法，也没有据缺少 GPU 回传否定当前软件研究。

R1-M1 与 R3-M4 独立发现了同一个约束输出缺口。R1 将其列为阻断，R3 将其列为非阻断，综合保留这一严重性差异，优先修复后验对象入口。R1-M2 与 R3-M3 对失败轨迹保留的判断一致，均属非阻断 Major。

R3-M1 单独发现分析协议与原始记录的身份关联缺口，并列为阻断。R1-M3 对不完整末窗口停止规则的质疑，以及 R2-M1、R2-M2 对失败成本和常量诊断的质疑，也均有具体代码依据。它们不是三方共识，不能为了形成共识而改写独立报告。

## 剩余范围

正式CPU结果、GPU性能、跨机器结论和正式SBC仍须以完成记录判断。软件修复在独立候选目录实施，冻结CPU v1继续使用原源码。后续发布采用不同版本，原源码、协议和结果不覆盖。不同源码版本的CPU/GPU结果不能被直接解释成纯硬件加速比。

不存在共同的 Nature 投稿结论。受众和意义目前限于贝叶斯计算、R/Stan使用者及科学软件复现研究；真实应用推广、自动配置和一般统计保证均没有得到确立。
