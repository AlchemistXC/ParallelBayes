# F3就绪验证伴随证据

v1与v2均为开发性就绪验证，不是正式推断比较。v1：9目标中1个完成、8个失败；v2：9/9目标、45/45工作流完成。原始失败输出不升级为普通样本。这里保存小型日志、状态、现代诊断和版本对照；完整原始数组与二进制回写保存在独立证据包中。

`analysis-v2/checksums.json`是完整原分析目录的清单，包含未直接提交Git的binary/roundtrip；不是仅本小型目录的自包含清单。完整证据包才能逐项校验这些条目。本目录外层SHA256SUMS覆盖实际跟踪文件。

所有六项新测试只覆盖新坐标/基线接口，不追加到历史采样器65/63项计数。45份工作流只有每目标一次开发性运行；不能当作45次独立统计重复。v1/v2共享实际输入，也不是独立重复。完整解释见docs/F3-INFERENCE-READINESS.md。
