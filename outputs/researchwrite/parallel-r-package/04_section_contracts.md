# 本轮交付契约

| 内容 | 目的与输入 | 允许结论 | 验收 |
|---|---|---|---|
| 审核结论 | 原方案、现稿、核查来源 | 有条件可行及主要改动 | 不承诺发表或提速 |
| 软件与语言 | 官方 API、仓库实现 | 支持边界及架构判断 | 区分接口存在/代码审查/运行验证 |
| 统计协议 | 公式、文献和专项审查 | 明确参考误差、停止与选择规则 | 不把诊断当真值或证明 |
| 修订计划 | 已有硬件与方法风险 | 小型预实验和继续/缩减判据 | 不形成未经授权的部署/安装 |
| 研究贡献 | 既有基准/时间并行工作 | 可检验的候选增量 | 不宣称未证实的首次 |

## 统一研究与开发计划的章节契约

| 章节 | 目的与输入 | 允许/禁止的内容 | 核查规则 |
|---|---|---|---|
| 目标与贡献 | 问题、前作与审核 | 可证伪假设；禁止预写性能结果 | 每个问题关联实验与结果 |
| 范围与架构 | 用户硬件、官方接口 | 决定首版组合；禁止暗示任意 Stan 自动 GPU | 支持矩阵全部标记计划状态 |
| 输出与随机输入 | 两条路线及保证边界 | 明确结果/失败/回退；禁止容差当严格确认 | 不同保证独立描述 |
| 验证与实验 | 统计专项 | 模型、核、预算、参考、误差协议 | 固定 N 与墙钟截止、离线与运行时检查分开 |
| 开发阶段 | 工程专项 | 依赖、任务、验收、停止与缩减 | 每项有可检查产物，不承诺未经测试工期 |
| 写作与发布 | 当前综述、候选基准 | 实验后重构稿件 | 无实验前不改写贡献为已发现 |
