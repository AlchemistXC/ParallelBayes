## 已落实、建议保留的边界

1. **支持范围明确。** §2 将 JAX 的 MALA/quasi-DEER、RWM/Picard 两条路径，与 BridgeStan 的 CPU 顺序 RWM/MALA 分开。BridgeStan CPU Picard 是条件扩展，任意 Stan 自动 GPU 未支持。公开说明应沿用此矩阵；首版仍不能承诺“任意 Stan 模型一键时间并行”。
2. **路线与回退相容。** WP02 先完成 MALA 审计，WP03 依论文独立实现 Picard；Picard 暂未完成只能称内部单路线原型。§4 明确 quasi-DEER 有限容差点不能自动成为可回退的已确认前缀，回到初值/独立确认检查点重算，且成本入账。
3. **CPU 并发没有由指针复制推断安全。** §3 管理 worker 内模型创建、编译条件、RNG/缓冲所有权及嵌套线程；WP05 有生命周期和资源任务。BridgeStan 的二阶导数来源与完整转移导数分别记录。
4. **代码许可不阻塞独立科学实现。** ParallelMH 未确认再分发许可，计划不直接复制发布；依据论文独立实现并保留来源。已许可上游保留版本、依赖与适配差异。
5. **硬件策略与已知资源一致。** Mac/CPU 用于正确性，AMD CPU＋5080 Win11 台式机先作 WSL2/JAX GPU 验证。计划没有把官方可用路线写成该机实测成功，也没有以 Mac/台式机跨硬件差异解释算法加速。GPU 部分未就绪时可继续 CPU 验证。
6. **阶段依赖基本成立。** WP01 依赖 WP00 CPU；WP02/03 都有独立参考；WP04 可以先形成 MALA 小报告但完整最小版仍依赖 WP03；WP06 在开发性探测后冻结，WP07 不反向选择有利模型；WP08 可删除，WP09 不依赖它。
