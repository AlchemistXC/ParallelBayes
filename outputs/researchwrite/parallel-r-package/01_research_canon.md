# 事实与边界

1. 现有论文明确贡献为证据综合，无自有性能实验；第 7.2 节已提出计入探测成本的资源选择问题。
2. 同一后验分布、同一无约束坐标密度、同一转移核、同一随机输入轨迹是不同要求。
3. Stan/BridgeStan 是可用模型入口；其接口并不自动构成原生 JAX/GPU 图。NIMBLE 也支持 AD/HMC，不能用 BUGS 语法否定梯度方法。
4. Newton 方法所需转移导数不能用目标密度 HVP 接口直接替代。BridgeStan 二阶导数的计算方式、编译选项和模型支持范围必须记录。
5. Picard 已确认前缀、quasi-DEER 数值收敛、有限迭代近似输出不能混称“精确采样”。
6. 软件公开、可复现实验、可复用并行内核、允许再分发是不同事实，逐项确认。
7. compareMCMCs、PPL Bench、Inference Gym、posteriordb 和时间并行实现已有先例。“统一接口”和“系统比较”自身不足以主张首次贡献。
8. 性能收益、低成本选择器价值、周数估算均尚未通过本项目实验确认。
9. Mac 作为开发/正确性环境；5080 台式机是 GPU 预验证候选。JAX 官方对原生 Windows NVIDIA GPU 不支持、WSL2 为实验性支持；本轮未实测该机器。
10. 参考样本存在 Monte Carlo 误差；SBC 是诊断而非完整正确性证明；运行到墙钟截止时返回结果的规则属于被评价算法的一部分。
11. 禁止把未运行的测试写成通过，把未观察的速度提升写成结果，把未确认的全领域空白写成首次。

## 2026-10-03 计划决策

以下是研究设计决定，不是已实现能力或实验事实：先完成原生 JAX MALA 的同后端顺序/窗口 quasi-DEER 验证；再独立实现并验证 Online Picard；Stan/BridgeStan 先接 CPU 顺序核，R 作为批量控制与分析层。BridgeStan CPU Picard 列为有条件扩展，不把未实现的并行组合宣传为首版支持。自动配置、HMC 时间并行及新语言均不作为最小版验收条件。

初始探测采用两模型族四个任务和一个约束变换夹具；任务具体设计、阈值制定规则及输出状态由主计划定义。正式研究的模型库、重复数和预算在独立探测后冻结；该冻结文件尚未产生，不代表本轮研究计划没有写完。
