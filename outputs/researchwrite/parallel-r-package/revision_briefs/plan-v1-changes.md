# 研究与开发计划 v1.0 修订记录

2026-10-03。用户要求将上一轮审核落实为当前计划。本轮从审核建议和原方案编写统一计划，不再只输出评语。

| 审核问题 | 现计划落实位置 |
|---|---|
| 语言与开发顺序混淆 | §2 标准 Stan 入口/原生 JAX 内核分开，§9 先 WP01–04 再 WP05 |
| 所有组合似乎都支持 | §2 组合矩阵全部标为计划/条件扩展/首版不支持 |
| HVP 与转移导数混淆 | §3 导数来源、二阶构建、核/执行器职责 |
| 研究代码直接包装风险 | §4 求解终止/残差/修复/回退，§10 来源与许可 |
| 同轨迹与近似输出混称 | §4 保证、数值证据、运行状态分别记录，§8 E1/E2 分开 |
| 参考误差、截止与失败未定义 | §8.2–8.4 参考分解、重复不确定性、输出及完整成本 |
| 只有原则没有初始任务 | §6 两模型族四任务、夹具、初始网格与独立随机输入 |
| 统计正确性缺负责关卡 | WP04/V4 解析函数与小型 SBC，WP05 新接后端核验，WP06 正式协议 |
| NUTS 最小版和正式基线混淆 | WP05 外部适配小案例，WP06 基准调参与冻结 |
| 选择器存在留出泄漏风险 | §8.5 在 WP06 封存，或 WP08 另建未参与开发的测试族 |
| 工期无实测依据 | §9 以产物/验收关卡推进，WP02/WP06 后按实际成本估算 |
| 论文过早转型 | §12 保留综述，WP07 之后形成实证贡献，WP08 可删除 |

保留的正确设计：模型/核/执行器分离，同设备同后端，同随机输入，完整成本、失败记录与模型族检验。没有扩大为新语言、动态 NUTS 时间并行或多机系统。

独立专项 QA 后作三项修复：补 V4 工作包映射、统一 NUTS 适配关卡、防止选择器留出泄漏；另外明确误差阈值为 ε²。所有研究数字均标为设计值；没有把计划验收项勾为已完成。
