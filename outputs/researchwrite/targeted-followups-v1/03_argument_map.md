# 论证结构

已完成研究给出了指定实现的路径、耗时和有限预算误差，但三个限制尚可解释得更充分：路径超限如何影响函数；进程失败发生何处；有限参考影响多大。中心问题是：用有界补充工作，能否缩小这三个解释范围，而不改写旧结果？

S1固定所有既有输入，只增加函数层对照；S2先从既有输出隔离诊断，再用少数受控四链调用定位阶段；S3把确定数值误差包络与随机参考MCSE分开。预期交付为可复核的差异表、阶段证据图和参考精度表，不预期必然修复、认证或提升排名。

主要反例：小平均差可掩盖局部差；禁用诊断后成功可能受并发/记录影响；高精度同值不排除共同求积偏差；大IS ESS不等于稀有事件可靠。逐项用点差与均值、2×2条件、内外域包络、分子/分母独立质量诊断约束。
